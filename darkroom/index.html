Concepts 抽卡邏輯教學

「一般」分頁是全域控制面板，Concepts 抽卡完全照這裡的設定判斷

「參與判斷／已跳過」——這格算不算數

「一般」分頁 LoRA1／LoRA2 各自一顆切換按鈕，預設是「已跳過」：
已跳過預設狀態——這格不管放了什麼 LoRA、範圍晶片設什麼，Concepts 判斷時都當它不存在
參與判斷手動切成這個，這格才會影響 Concepts 抽卡
這樣手動在 LoRA1/2 放 LoRA 做一般生圖，不會不小心也悄悄改變 Concepts 抽卡的結果——想讓 Concepts 用到某格，要自己明確打開。

每格套用哪顆 LoRA

對每個「參與判斷」的格子：
  1. 固定 LoRA 優先——格子裡已經放著一顆 LoRA → 每張卡都鎖定用這顆，不限分類，放什麼就套什麼，不隨機
  2. 範圍晶片其次——沒有固定 LoRA，但格子的範圍晶片縮小了分類/子資料夾 → 每張卡在那個範圍內各自重新隨機
強度就是這格自己的強度滑桿（LoRA 大面板／「一般」分頁是同一份，改哪邊都同步），不分角色。

情境（concepts）的自動補位——只有 C 會這樣做

兩格都沒有情境訊號（沒有固定在 HENTAI/concepts 資料夾裡的 LoRA、範圍晶片也沒設成 HENTAI 分類），且至少有一格還是「已跳過」（代表還有空位）時，C 會自動幫那個空格補一顆全庫隨機 concepts，強度沿用那格自己的設定。R／E 不會自動補位，單純照兩格現在的樣子字面套用——例如兩格都固定了跟 concepts 無關的 LoRA，R／E 就只套那兩顆。

範例：LoRA1 固定角色、LoRA2 隨機補情境

  1. LoRA 大面板選好角色 LoRA 放 LoRA1
  2. 「一般」分頁把 LoRA1 切成「參與判斷」（在大面板選定的當下其實已經自動切了，不用手動再點一次）
  3. LoRA2 維持預設「已跳過」，不用特別設定
  4. 按 C——每張卡 LoRA1 都是同一顆角色 LoRA，LoRA2 自動補一顆全庫隨機 concepts、每張卡重抽；按 R／E 則只套 LoRA1 那顆，不會補

模板怎麼決定

C 看「Concepts」分頁的「同時抽詞庫模板」「模板只抽左邊目前資料夾」兩個勾選：都不勾就不套模板，只用 LoRA 觸發詞當 prompt；勾了才會另外隨機抽一個詞庫模板（勾「只抽左邊」就只在目前資料夾裡抽，否則全部詞庫都可能抽到）。R 無視這兩個勾選，固定從全庫抽模板；E 也無視勾選，固定限目前左邊選中的資料夾——跟 R／E 在瀏覽/生圖模式下的既有意思一致。
